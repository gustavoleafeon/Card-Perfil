Uso do negrito

O uso do negrito é feito com a tag "b", conforme o exemplo a seguir: Negrito

O italico deixa a fonte de uma forma mais cursiva, é declarado com a tag "i", exemplo: Italico

O negrito e o italico podem ser combinados: Negrito e Italic

O sublinhado é declarado com a tag "u", exemplo: Sublinhado

Utilizando a semântica do negrito e itálico

O HTML semantico tem como objetivo descrever o significado do conteudo presente em docs HTML, tornandos-o mais claro para os programadores quanto para od navegadores. Exemplo: programador web
